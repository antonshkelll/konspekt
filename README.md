# Konspekt · персональная бета

Windows-помощник для встреч: реплики «Я» и «Собеседники», файлы контекста, автоматические подсказки, итоги и экспорт в Markdown.

## Запуск

Готовая сборка после `build.bat`: `dist/Konspekt.exe`. Из исходников: `start-beta.bat` (Python 3.12+, зависимости устанавливаются автоматически).

1. Открой **Настройки**. По умолчанию выбраны **DeepSeek** для ответов и **Deepgram** для потокового распознавания.
2. Создай ключ DeepSeek в https://platform.deepseek.com и ключ Deepgram в https://console.deepgram.com. Вставь в соответствующие поля настроек. Не отправляй ключи в переписку или Git.
3. Модель ответов — `deepseek-flash`, thinking отключён явно, ответ выводится по мере генерации. Модель можно изменить. API DeepSeek платный: https://api-docs.deepseek.com/quick_start/pricing/.
4. Прикрепи TXT, MD, CSV, DOCX или текстовый PDF, добавь повестку. Текст вложений отправляется выбранной LLM при запросе.
5. Предупреди участников о расшифровке и нажми **Начать запись**. Для уменьшения дублей используй наушники.
6. Включи **Автоподсказки**, если нужны ответы без нажатия кнопки. Или введи вопрос вручную.

Проверка API в настройках проверяет каталог моделей; она не гарантирует наличие квоты на генерацию. Проверка баланса относится к Deepgram/OpenRouter.

## Возможности беты

- DeepSeek: прямой API без посредника, отключён thinking, автозапрос после финальной реплики собеседника и паузы от 350 мс, проверка условий каждые 250 мс. Это программные задержки, не обещание времени ответа API.
- Groq: один ключ для LLM и Whisper, без обязательного платного OpenRouter.
- Ollama: локальная или собственная серверная LLM. [Инструкция MobaXterm / SSH](deploy/README.md).
- До пяти файлов контекста: каждый до 5 МБ, суммарно до 16 000 символов. PDF без OCR, до 50 страниц. Длинные документы нужно сократить.
- Автоподсказки только при новых репликах собеседника и без активного ответа. DeepSeek: минимальный интервал 1 секунда, Groq — 30 секунд, Ollama/OpenRouter — 15 секунд. Ручной запрос откладывает автоматику на 30 секунд. Ошибка ответа отключает автоматику. Автоматика расходует API-баланс.
- Под ответом показывается фактическое время до первого текста после отправки запроса (без задержки распознавания).
- Трей: открыть окно, остановить запись, выйти. Убирание окна из панели задач включается в настройках; процесс остаётся виден в диспетчере задач.
- Исключение окна из захвата экрана через штатный Windows API, включается отдельно. Проверь результат в своей программе созвонов: гарантии для всех способов захвата нет.
- Отсечение запоздавших ответов отменённого запроса и событий прошлой встречи.

## Бесплатность и задержки

У Groq есть бесплатный план с лимитами запросов, токенов и аудио: https://console.groq.com/docs/rate-limits.
Чтобы использовать его, выбери Groq отдельно в провайдерах ответов/речи и вставь ключ https://console.groq.com/keys.
Квоты и модели зависят от аккаунта и могут меняться. Автоматического переключения на платного провайдера нет.
Собственный сервер требует ресурсов и оплаты инфраструктуры.

Groq STT отправляет каждый источник отдельными WAV-фрагментами по 8 секунд: около 15 запросов/минуту для двух источников.
Задержка — 8 секунд + сеть/обработка. Последний короткий фрагмент отправляется после остановки; дождись текста перед экспортом.
При перегрузке очереди фрагменты могут теряться, это отображается в статусе. Очень тихая речь может отсекаться фильтром тишины.
При отказе ключа или исчерпании квоты STT запись останавливается. Для потоковой речи можно выбрать Deepgram (его оплата отдельная).

В Groq отправляются последние 2000 символов разговора, до 800 символов повестки и начальные фрагменты каждого файла (всего до 3500 символов контекста).
Так ограничивается расход квоты; детали глубоко в документе могут не попасть в запрос. Семантического поиска по документам пока нет.
Для DeepSeek/Ollama/OpenRouter — последние 12 000 символов разговора, до 4000 символов повестки и весь разрешённый текст вложений.
Кнопка итогов тоже использует это окно: полные итоги очень длинных встреч пока не гарантируются.

## Данные

Запись начинается вручную; состояние видно в окне и подсказке трея. Аудио на диск не сохраняется.
При выборе Groq аудио отправляется Groq; при Deepgram — Deepgram. Текст, повестка и вложения отправляются провайдеру ответов.
Выбор Ollama переносит только LLM: распознавание речи пока облачное.
Ключи и настройки: `%APPDATA%/Konspekt/config.json` в открытом виде в профиле Windows. Не публикуй этот файл.
Вложения хранятся в памяти до новой встречи/выхода. Заметки сохраняются вручную в `Documents/Konspekt`.
