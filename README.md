# Konspekt — ИИ-помощник для встреч

Windows-приложение: в реальном времени расшифровывает созвон (твой микрофон и звук собеседников отдельно), а потом по кнопке делает итоги, задачи, follow-up письмо или отвечает на вопросы по встрече.

Работает с любой платформой — Яндекс Телемост, Контур.Толк, Teams, Zoom, Meet: звук собеседников берётся из системного вывода Windows.

## Возможности

- Живая расшифровка на русском, реплики подписаны: «Я» / «Собеседники».
- **Итоги и задачи** — темы, решения, задачи «кто — что — срок», открытые вопросы.
- **Что я пропустил?** — пересказ последних 5 минут.
- **Письмо после встречи** — черновик follow-up.
- Свободные вопросы по встрече: «какие цифры называл заказчик?», «о чём договорились по срокам?».
- Поле «О чём встреча» — повестка и термины, чтобы ИИ лучше понимал контекст.
- Сохранение заметок в Markdown: `Документы\Konspekt`.

## Запуск

1. Скачай `Konspekt.exe` (или собери сам, см. ниже) и запусти.
2. **Настройки** → вставь ключи:
   - [Deepgram](https://console.deepgram.com) — распознавание речи (при регистрации дают стартовый баланс);
   - [OpenRouter](https://openrouter.ai/keys) — доступ к Claude, GPT, Gemini одним ключом.
3. Нажми **Начать запись** и предупреди участников, что ведёшь расшифровку.

Настройки и ключи хранятся локально: `%APPDATA%\Konspekt\config.json`.

Модели по умолчанию: `anthropic/claude-sonnet-5.5` (итоги, вопросы) и `anthropic/claude-haiku-5.5` (быстрый пересказ). Любую можно поменять в настройках на другую модель из каталога OpenRouter.

## Сборка

```bat
build.bat
```

Создаст `dist\Konspekt.exe`. Нужен Python 3.12+.

Для разработки:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run.py
```

## Структура

```
konspekt/
  app.py       окно и логика интерфейса
  capture.py   захват звука (WASAPI) и потоковая расшифровка Deepgram
  llm.py       запросы к моделям через OpenRouter
  config.py    настройки
tools/make_icon.py  генерация иконки
```
