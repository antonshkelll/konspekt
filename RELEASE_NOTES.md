# Konspekt 0.4.0 — ChatGPT plan usage

Личный локальный помощник для Windows: микрофон и системный звук → расшифровка → ответы в прозрачной панели.

- Официальный Continue with ChatGPT с отдельным разрешением использования плана подходящего Plus/Pro-аккаунта.
- Модели выбираются из каталога аккаунта. Обычный API-ключ для этого режима не используется; автоматического платного fallback нет.
- OAuth-секреты защищены Windows DPAPI и не включены в архив. На другом компьютере нужно войти самостоятельно.
- Очередь обоих голосов, файлы контекста, история ответов, регулируемый прозрачный фон и экспорт заметок.

В проверенном аккаунте запрос через разрешённый план завершён успешно: первый текст 5,50 с, полный ответ 5,79 с. Это один замер, а не гарантия задержки. 28 автотестов проходят.

Распакуйте архив целиком и запустите `KonspektSubscription/Konspekt.exe`. Папка `auth-runtime` обязательна. Инструкции — `CHATGPT_PLAN.md` и `USER_GUIDE.md` внутри пакета.

Распознавание речи пока использует отдельно настраиваемый Deepgram/Groq; оно не входит в OAuth-разрешение ChatGPT plan usage. Доступны лимиты подписки, безлимит не заявляется. Невидимость в конкретном клиенте демонстрации экрана не гарантируется; процесс остаётся виден в диспетчере задач.

Пакет предназначен для личного некоммерческого использования. Включён официальный OpenAI Sign in with ChatGPT DevKit с его Noncommercial License, а также лицензии Node.js и зависимостей. Для коммерческого использования вклада DevKit требуется отдельное соглашение.
