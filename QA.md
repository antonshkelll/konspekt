Автотесты покрывают HTTP SSE, ошибки API и обрыв потока, маршрутизацию Ollama/DeepSeek, `thinking=disabled`, финальный WAV-фрагмент и сведение стерео в моно, отказ квоты STT, ограничения вложений, изоляцию встреч/ответов, автоматику и передачу ответа из фонового потока в Qt с контекстом вложения.

Проверки, которые пока не выполнены:

- Живые DeepSeek и Deepgram: при проверке ключей в настройках не было. Нужны ключи, тестовый разговор и измерение полной задержки «конец речи → первый текст».
- Демонстрация экрана в конкретном клиенте созвона: успешный Windows API не доказывает исключение окна во всех способах захвата.
- Полный сценарий реальных кликов/трея: инструмент управления Windows вернул `FrameArrived timed out`, затем `coordinate input geometry is unavailable`. Дерево элементов доступно, но это не зачтено как успешный сценарий кликов.
- Серверный Ollama: подготовлен Compose и SSH-инструкция; на сервере не развёрнут и не проверен.

В локальном тесте аудиоустройств аудио не сохранялось и не отправлялось по сети. Ключи и личные материалы в тестах не использовались.
