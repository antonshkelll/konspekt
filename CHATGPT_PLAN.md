# Использование своего плана ChatGPT

Обычный API-ключ использует отдельный API-баланс. Для личного локального проекта есть другой официальный маршрут: **Sign in with ChatGPT → ChatGPT plan usage**. По документации 14.11.2026 подходящие Plus/Pro-аккаунты могут разрешать такие запросы. Это не выдача API-кредитов Plus и не безлимитная работа.

## Вход

1. Используй полный пакет: EXE вместе с папкой `auth-runtime`.
2. Настройки → **ChatGPT · использовать свой план** → **Continue with ChatGPT**.
3. Самостоятельно войди в браузере и разреши использование плана приложением Konspekt. Пароль и коды подтверждения вводятся только на странице OpenAI. Настройки приложения не закрывай до завершения.
4. Дождись сообщения **Using ChatGPT plan** и загрузки каталога доступных аккаунту моделей. Модель выбирается из этого каталога; Luna предпочитается только если она действительно доступна.
5. Нажми проверку ответа и скорости. Успешный вход сам по себе ещё не доказывает успешную генерацию. При отказе разрешения, исчерпании лимита или недоступности модельного доступа платный API не включается автоматически.
6. Сохрани настройки и начни запись. Расшифрованные реплики передаются Responses API с отдельным OAuth-разрешением. Открытый чат на ноутбуке и скрипт управления браузером не нужны.

Управление разрешением и лимитами: https://chatgpt.com/settings/usage. Потребление зависит от модели и аккаунта; лимиты этого режима не обещаются равными числу сообщений обычного ChatGPT Chat. Отдельные покупки дополнительных кредитов приложение не выполняет.

## Секреты и хранение

Токены хранятся отдельно от `config.json`: `%APPDATA%/Konspekt/chatgpt`. DevKit проверяет OIDC, state, nonce и PKCE, обновляет токены и использует стабильный host ID. Учётные данные зашифрованы Windows DPAPI для текущего пользователя. В интерфейс и stdout возвращаются только безопасное состояние подключения, модели и текст ответа.

Приложение не читает браузерные cookie, чужие сеансы или токены Codex. Ключ OpenAI API остаётся отдельным, вручную выбираемым провайдером. Распознавание речи пока использует Deepgram/Groq: этот канал не покрывается данным разрешением ChatGPT plan usage.

## Сборка из исходников

Нужен Node.js 22.12+ и npm. Выполни `npm ci` в папке `siwc`, задай `KONSPEKT_NODE` абсолютным путём к актуальному `node.exe` (если он не обнаруживается автоматически), затем `build.bat`. В `dist` будут EXE и `auth-runtime`. Переносить нужно обе части; копировать только EXE недостаточно. Готовый пакет не содержит авторизации: на другом устройстве пользователь входит сам, с отдельным стабильным host ID.

Для коммерческого использования вклада DevKit требуется отдельное соглашение. Возможность входа и фактическое использование плана подтверждаются только после согласия пользователя и завершённого запроса `response.completed`.
