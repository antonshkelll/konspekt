# Konspekt: рабочий запуск

## Использование подписки Plus без обычного API-ключа

Используй официальный **Sign in with ChatGPT**: [инструкция входа и использования плана](CHATGPT_PLAN.md). Утверждение ниже про отдельную оплату относится именно к API-ключу. ChatGPT plan usage — отдельный разрешаемый пользователем маршрут для подходящих локальных приложений; это не API-кредиты Pro/Business.

## Выбранный профиль: OpenAI API + Deepgram

1. В API Platform создай проектный API-ключ: https://platform.openai.com/api-keys. Нужен доступный API-баланс. Вводи ключ только в настройках Konspekt.
2. Настройки → провайдер ответов **OpenAI API** → ключ → модель `gpt-6-luna`. Это исходный экономичный профиль для коротких ответов. Для более сложных задач можно отдельно проверить `gpt-6.1-terra`; доступность и расходы зависят от API-аккаунта.
3. Нажми **Проверить ответ и скорость**. Отправляется синтетический тестовый вопрос, который тарифицируется API. Успешная проверка показывает фактическую задержку, а не обещание мгновенного ответа. Ошибка 401 означает отказ ключа; 429 может означать отсутствие квоты/баланса или превышение лимита.
4. Речь: **Deepgram**, существующий ключ, прямое соединение. Распознавание оплачивается/ограничивается отдельно от LLM.
5. Сохрани настройки. Добавь контекст или документы, предупреди участников о расшифровке, нажми **Начать запись**. Компактная панель и очередь обоих голосов включатся автоматически.
6. Закончи запись до завершения приложения. Экспортируй заметки. Личная повестка и ключи сохраняются в профиле Windows; файлы контекста и история ответов текущей встречи находятся в памяти.

OpenAI API не расходует обычный лимит сообщений ChatGPT Plus. На дату проверки 14.11.2026 включённые API-кредиты описаны для подходящих Pro/Business, а Plus не входит в эту льготу. Личный ключ ассистента/этого чата приложению не предоставляется.

Источники: https://developers.openai.com/api/docs/guides/chatgpt-api-credits и https://developers.openai.com/api/docs/models/gpt-6-luna.

## Бесплатная квота облачной LLM

Можно выбрать **Groq** и ввести свой ключ https://console.groq.com/keys. Начальный кандидат — `openai/gpt-oss-20b`. Для него запрашивается низкий reasoning и увеличенный общий лимит, чтобы reasoning не вытеснил готовый ответ. Квоты ограничены: https://console.groq.com/docs/rate-limits. Без действующего ключа живое тестирование невозможно. Проверка готовности не обещает, что квоты хватит на весь звонок. Автоматического платного переключения нет.

## Компьютер и ноутбук

Проще всего: запускай Windows-клиент там, где проходит созвон. Он захватывает микрофон и системный звук именно этого устройства. OpenAI/Groq подключаются напрямую, ноутбук как промежуточный сервер не нужен.

Если хочешь использовать Ollama ноутбука с Windows-ПК: оставь Ollama на ноутбуке на loopback и настрой доступный тебе SSH-сервер. На ПК открой туннель:

```text
ssh -N -L 127.0.0.1:11435:127.0.0.1:11434 USER@LAPTOP
```

В Konspekt на ПК: Ollama, URL `http://127.0.0.1:11435/v1`, имя установленной на ноутбуке модели. Необходимы реальный адрес ноутбука и работающий SSH-доступ. Этот маршрут пока не проверен между двумя компьютерами. Он не ускоряет CPU ноутбука; измеренная ранее локальная Qwen могла ждать десятки секунд. Публично открывать порт Ollama не требуется.

Пакет для Windows-ПК включает только EXE и эту инструкцию: ключи, документы, модели и личные настройки туда не включаются. На втором компьютере потребуется собственная настройка провайдеров. macOS/Linux-клиенты в эту сборку не входят.
